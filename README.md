# 🏎️ Muscle Cars Legends - Bootstrap Project

Este proyecto es una página web responsiva dedicada a los íconos del automovilismo americano. Fue construida utilizando el framework **Bootstrap 5**, enfocándose en la simplicidad, la velocidad de carga y un diseño moderno que se adapta a cualquier dispositivo.

## 🚀 Características del Proyecto
* **Diseño Mobile-First:** La interfaz está optimizada para verse perfectamente tanto en móviles como en computadoras utilizando el sistema de rejilla de Bootstrap.
* **Integración via CDN:** Uso de **jsDelivr** para cargar los estilos y scripts, asegurando una carga rápida y eficiente.
* **Componentes Dinámicos:** Implementación de `Navbar`, `Cards` con efectos de elevación y una sección `Hero` con filtros visuales.
* **Organización de Código:** Estructura limpia y semántica en HTML5 y CSS3.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Para la estructura y semántica del sitio.
* **Bootstrap 5.3:** Para el diseño responsivo y los componentes pre-diseñados.
* **CSS3:** Estilos personalizados para animaciones (`hover`) y personalización del Hero.
* **Cloudflare/jsDelivr:** Para la entrega de contenido (CDN).

## 📂 Modelos Destacados
1. **Ford Mustang Boss 429:** La leyenda de 1969 diseñada para las pistas.
2. **Dodge Charger R/T:** El músculo americano por excelencia con motor HEMI.
3. **Chevrolet Camaro Z/28:** La respuesta ágil y potente de Chevy para la competición Trans-Am.

## ⚙️ Cómo Visualizarlo Localmente
1. Clona este repositorio o descarga el archivo `index.html`.
2. Abre el archivo en tu navegador preferido.
3. *Nota: Se requiere conexión a internet para que los estilos de Bootstrap y las imágenes se carguen correctamente desde los servidores externos.*
