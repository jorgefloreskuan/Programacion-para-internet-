# 📝 Mis Tareas - Gestor de Tareas Personal

Una aplicación web moderna y minimalista para gestionar tareas diarias. Diseñada con un estilo "Tech" (Negro/Verde/Azul) y funcionalidades avanzadas para mejorar la productividad.

## ✨ Características Principales

Este proyecto no es solo una lista simple, incluye funcionalidades completas:

-   **🎨 Modo Claro / Oscuro:** Interfaz adaptable con persistencia de preferencias (guarda tu elección).
-   **📅 Gestión de Fechas:** Asignación de fechas límite con alertas visuales para tareas vencidas o urgentes.
-   **🏷️ Categorías:** Clasificación de tareas (Trabajo, Personal, Estudio, Hogar) con etiquetas visuales.
-   **✏️ Edición:** Posibilidad de modificar el texto de las tareas existentes.
-   **💾 Persistencia de Datos:** Uso de `localStorage` para que no pierdas tus tareas al cerrar el navegador.
-   **⚡ Animaciones:** Transiciones fluidas al agregar y eliminar tareas.
-   **🔍 Filtros:** Visualiza todas, solo las pendientes o solo las completadas.

## 🛠️ Tecnologías Usadas

El proyecto fue construido utilizando tecnologías web estándar, sin dependencias externas:

* **HTML5:** Estructura semántica.
* **CSS3:** Variables CSS (Custom Properties), Flexbox, Animaciones y Diseño Responsivo.
* **JavaScript (ES6+):** Lógica del DOM, manejo de Eventos y LocalStorage.

## 🚀 Cómo usar este proyecto

No requiere instalación (Node.js no es necesario). Es una aplicación estática.

1.  **Descarga o Clona** el repositorio.
2.  Abre el archivo `index.html` en tu navegador web favorito (Chrome, Firefox, Edge).
3.  ¡Empieza a organizar tus tareas!
